# Android-обёртка «Слово дано»

Маленькое приложение (Trusted Web Activity), которое открывает твой сайт на Cloudflare как обычное
Android-приложение: без адресной строки, со своей иконкой. Весь код, данные, push и автообновление остаются
в веб-приложении. Обновлять APK после деплоя сайта не нужно.

Адрес сайта задан в `app/build.gradle.kts` (`siteHost`). Идентификатор приложения: `app.slovodano`.

## Сборка в Android Studio

1. File → Open, выбери папку `android` из репозитория (не корень репозитория). Дождись Gradle Sync.
   Если Studio предложит обновить Gradle или плагин Android, соглашайся.
2. Если синхронизация не находит библиотеку `androidbrowserhelper:2.6.2`, замени версию на `2.2.0`
   в `app/build.gradle.kts`.
3. Подключи телефон (отладка по USB включена) и нажми Run. Или Build → Build APK(s) и поставь `app-debug.apk` вручную.

## Чтобы пропала адресная строка (Digital Asset Links)

Chrome убирает строку адреса, только если сайт подтвердит, что это приложение ему доверяет.
Без этого приложение работает, но сверху виден адрес сайта.

1. Узнай отпечаток SHA-256 ключа, которым подписан установленный APK.
   Для отладочной сборки Android Studio:
   ```bash
   keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
   ```
   Строка `SHA256:` в выводе. Для релизной сборки используй отпечаток своего ключа (Build → Generate Signed Bundle / APK).
   Если нужны обе сборки, добавь оба отпечатка в список.
2. Вставь отпечаток в `public/.well-known/assetlinks.json` вместо заглушки, формат `AA:BB:CC:...`.
3. Задеплой сайт: `npx wrangler deploy`.
4. Открой в браузере `https://<твой-адрес>/.well-known/assetlinks.json`. Должен показаться этот файл.
   Если там ошибка 404, напиши мне: возможно, Cloudflare не загрузил папку с точкой в названии.
5. Переустанови приложение (или очисти его данные и Chrome-кеш для сайта) и открой заново.

## Уведомления

Push работает как в Chrome: включи уведомления в настройках приложения (блок «Уведомления на этом устройстве»)
и разреши их. Приложение использует web push через Chrome, а не собственный механизм. Для этого на телефоне
должен быть установлен и обновлён Chrome. Ссылки из уведомлений (`/?habit=...`, `/?urge=...`) открываются
в приложении, если подтверждены Digital Asset Links.
